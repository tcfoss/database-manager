# TcfOss.DatabaseManager.MsSql.LibWrapper

A convenience wrapper for starting applications that use the SQL Server DatabaseManager provider.

The provider currently supports parsing and formatting, not definition loading or
migration generation. See the [startup guide](https://tcfoss.github.io/database-manager/libraries/quickstart/),
[SQL Server capabilities](https://tcfoss.github.io/database-manager/libraries/providers/#sql-server-parsing), and
[customization guide](https://tcfoss.github.io/database-manager/libraries/customization/).

[Source repository](https://github.com/tcfoss/database-manager)
