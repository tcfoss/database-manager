# TcfOss.DatabaseManager.Core.Hosting

Shared startup, dependency-injection registration, and logging for applications that use the core DatabaseManager services. Used by the DatabaseManager CLI and available for library consumers and caller-owned hosts.

See the [offline quick start](https://tcfoss.github.io/database-manager/libraries/quickstart/) and
[customization guide](https://tcfoss.github.io/database-manager/libraries/customization/).

[Source repository](https://github.com/tcfoss/database-manager)
